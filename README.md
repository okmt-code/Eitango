# 英語トレーニング(英単語・英文法・えいご あそび)

iPad・iPhone で使える英単語・英文法の練習アプリです(愛知県公立高校入試向け、教材はすべて自作)。
小学生向けの「えいご あそび」(絵を見て答える・聞いて選ぶ・アルファベット、1〜3年 / 4〜6年)も入っています。

- 公開ページ: https://okmt-code.github.io/Eitango/
- Safari で開き、共有ボタン →「ホーム画面に追加」でアプリのように使えます。一度開けばオフラインでも動きます。
- 学習記録は端末の中だけに保存されます。
